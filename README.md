## 적용 방법

1. [Releases](../../releases/latest)에서 패치 파일을 받습니다.
2. 직접 가지고 계신 원본 이미지의 **bin 파일**에 패치를 적용합니다.
   - PC 프로그램: Delta Patcher, xdelta UI 등 (파일이 커서 웹 패처보다 PC 프로그램을 권장합니다)
3. 패치된 bin 파일 이름을 바꿨다면 cue 파일 안의 파일 이름도 같이 고쳐 주세요.
4. cue 파일을 에뮬레이터로 열어 실행합니다.

### 체크섬 확인

패치는 **일본판 Rev 1 원본 이미지**(SCPS-10023, 트랙 1개 bin/cue, MODE2/2352)에 적용해야 합니다. 패치 후 bin은 828,136,848바이트로 커집니다.
